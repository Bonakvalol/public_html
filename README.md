Разработанный проект «Цветочный шарм» представляет собой веб-приложение для онлайн-заказа и доставки цветов. В ходе работы проведён анализ рынка услуг по доставке цветов, на основе которого сформулированы функциональные требования к системе.

Спроектирована архитектура веб-приложения и разработана структура базы данных, включающая таблицы для хранения информации о пользователях, заказах, индивидуальных заявках, отзывах и промокодах акции «Колесо удачи».

Серверная часть приложения написана на языке PHP с использованием технологии PDO для безопасного взаимодействия с базой данных MySQL и защиты от SQL-инъекций. Клиентская часть выполнена на HTML, CSS и JavaScript с подключением библиотеки jQuery.

В приложении реализованы регистрация и авторизация пользователей с разделением на три роли: гость, авторизованный пользователь и администратор. Создана функциональная корзина с сохранением товаров в локальном хранилище браузера и форма оформления заказа с выбором доставки или самовывоза.

Для пользователей разработан личный кабинет, где можно посмотреть историю заказов, оставить или отредактировать отзыв на выполненный заказ, изменить данные профиля и сменить пароль. Для администратора создана отдельная панель управления с дашбордом, отображающим статистику по заказам, выручке и отзывам, а также возможность управления заказами, индивидуальными заявками, пользователями и модерации отзывов.

Уникальной функцией приложения стало «Колесо удачи» — акция, доступная авторизованным пользователям раз в неделю. Анимация вращения колеса реализована с помощью Canvas, при остановке колеса случайным образом выпадает скидка от трёх до двадцати пяти процентов, после чего генерируется уникальный промокод и сохраняется в базу данных.

В ходе тестирования проверены все ключевые функции системы: регистрация, авторизация, добавление товаров в корзину, оформление заказа, отправка индивидуальной заявки, работа административной панели и вращение колеса удачи. Все тесты завершились успешно, ошибок не выявлено.

Разработанная платформа полностью соответствует поставленным требованиям, позволяет автоматизировать бизнес-процессы цветочного магазина, повышает качество обслуживания клиентов и эффективность работы персонала. В будущем приложение может быть расширено за счёт внедрения онлайн-оплаты, интеграции со службами доставки и создания мобильной версии.
